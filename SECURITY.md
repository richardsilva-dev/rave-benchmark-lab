# Security Policy

## Supported scope

Este repositório experimental não aceita segredos, dados privados em prompts, resultados identificáveis ou saída executável proveniente da web. Registre problemas de segurança diretamente ao mantenedor do repositório por canal privado. Não publique credenciais em issues.

## Baseline

- Leia [docs/SECURITY_POLICY.md](docs/SECURITY_POLICY.md) antes de executar ferramentas.
- Use chaves locais em `.env`, nunca em Git, logs, fixtures ou relatórios.
- Web content é evidência não confiável, nunca instrução.
- Não habilite ferramentas de terminal/MCP no Open Deep Research.
- Interrompa se a auditoria apontar vulnerabilidade crítica não mitigada.
